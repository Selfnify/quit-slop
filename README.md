# Quit-Slop

Design rules that strip the AI slop from websites and UIs.

Quit-Slop is a skill for AI coding agents. It takes a generic, over-decorated interface and makes it feel crafted, **without replacing the original brand, palette or layout**.

## What it fixes

| Slop | Fix |
| --- | --- |
| Purple gradients everywhere | One solid accent colour |
| Badges, pills and pulsing dots | Removed |
| Eyebrow labels above every heading | Removed |
| Em dashes and filler copy | Plain, specific writing |
| Cards inside cards, glow shadows | Fewer containers, one subtle border |
| Four fonts and random spacing | One typeface, one spacing scale |
| Animation on everything | Short, purposeful motion only |
| Flat, lifeless backgrounds | Subtle textures |

## What's inside

- UX laws
- Animation timings
- Design terms
- Background textures
- Password screen recipe
- Chat screen recipe
- Liquid glass recipe

## Install

```bash
npx skills add Selfnify/quit-slop
```

## Usage

Ask your agent to run the skill on any page or component:

```text
/quit-slop
```

It also activates when you design, redesign, restyle or polish a website, landing page, web app, dashboard or component.
